# Safe Telegram Device Control (Русский)

Этот проект предоставляет **безопасный** бот для управления *своими* устройствами через Telegram.
Он **не** делает вредных эффектов, поддельных ошибок или вмешательства в чужие окна.

## Возможности
- Регистрация нескольких устройств (агенты).
- Выбор нескольких устройств в Telegram.
- Разделы меню (Инфо / Файлы / Сообщения / Утилиты).
- Безопасные команды: системная информация, время, список папок в пределах base-dir,
  запись заметок, отчёт, пинг и т.д.
- Чат: агент отправляет сообщения в Telegram, а админ отвечает через `/chat`.
- Команды с параметрами через `/send <команда> <текст/путь>`.

## Запуск

### 1) Хаб (бот + HTTP сервер)

```bash
export BOT_TOKEN="<ваш_токен>"
export ADMIN_IDS="123456789,987654321"
export HUB_SECRET="change-me"
python3 safe_control.py hub --host 0.0.0.0 --port 8000
```

### Быстрые команды в Telegram

- `/menu` — открыть меню разделов.
- `/devices` — выбор устройств (множественный).
- `/send show_message Привет!` — сообщение на агенте.
- `/send create_folder папка` — создать папку в `base-dir`.
- `/chat Текст` — отправить сообщение в локальный чат агента.

### 2) Агент (на каждом устройстве)

```bash
export HUB_SECRET="change-me"
python3 safe_control.py agent --hub http://<IP_ХАБА>:8000 --name "PC-1"
```

## Безопасность
- Все файловые действия ограничены `base-dir` агента.
- Нет действий, которые могут пугать пользователя, подделывать ошибки или выключать ПК.
