# Система подписок Telegram с двумя ботами

Система из двух ботов:

1. **Админ-бот** — управление каналами, людьми, ценами, банками, номером телефона и статистикой.
2. **Платежный бот** — пользователь выбирает канал и срок, оплачивает через банковское приложение, отправляет фото чека.

После подтверждения чека админом бот создаёт одноразовую ссылку в канал. После окончания срока подписки пользователь автоматически удаляется из канала.

## Возможности

- `/people` — список пользователей и их подписок.
- `/price` — посмотреть текущие цены.
- `/price_edit` — редактирование прайса в формате `1 минут-10руб`.
- `/channel` — список каналов и инструкция.
- `/channels` — список каналов.
- `/statistics` — статистика заявок и подписок.
- `/phone` — изменить номер телефона для оплаты.
- `/banks` и `/banks_edit` — смотреть/редактировать банки.

### Автообнаружение канала

Если добавить админ-бота в канал (с правами приглашать пользователей и банить пользователей), он автоматически сохранит канал в БД через `my_chat_member` update.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# отредактируйте .env
python app.py
```

## Важно

- Укажите ID администраторов в `ADMIN_IDS`.
- Админ-бот должен быть администратором каналов.
- Платежный бот должен работать в личке с пользователями.
