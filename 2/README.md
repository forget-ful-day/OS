# Butterfly OS 13 (Python)

Прототип рабочего стола в стиле Windows 11 с меню «Пуск», проводником, установщиком приложений и поддержкой пакетов `.butterfly`.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pillow
python butterfly_os.py
```

## Что внутри

- Папка файловой системы: `filesystem/`
- Папка установленных приложений: `apps/`
- Данные и настройки: `data/`
- Магазин приложений с примерами: `sample_apps/`

## Учетные записи

По умолчанию создается пользователь:

- Логин: `admin`
- Пароль: `admin`

Новых пользователей можно создавать в приложении **Settings**.
